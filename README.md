# 上交所股票期权 · 模拟刷题

上交所股票期权投资者知识测试的**模拟刷题页**。纯静态、零依赖、无需后端，浏览器直接打开就能用，手机上也能单手刷。

## 在线访问

**https://ahazx.github.io/options-quiz/**

## 题库

- 来源：上交所股票期权模拟试题库（PDF，36 页）
- 共 **205 道单选题**，每题 4 个选项
- 答案为原题库答案表的值，未做改动
- 原题库只提供答案、没有逐题解析，所以页面不做解析编造

## 功能

### 答题

- 点击选项即作答，立即给出对错与正确答案
- 顶部进度条 + 底部题目导航（绿色 = 答对，橙色 = 错题）
- 点任意题号直接跳转
- 答题进度、错题、收藏、笔记全部存在浏览器本地，关掉再打开还在

### 界面

- **三种主题**：明亮 / 护眼米黄 / 深色，随时切换
- **沉浸模式**：隐藏题目导航和辅助信息，只留题目与选项，减少干扰
- **正向计时器**：默认显示用时，可在设置里关掉（不做倒计时，不制造紧迫感）
- **移动端优化**：单栏大卡片、底部固定操作栏、适配小屏与安全区域
- 反馈色用低饱和度的柔和色，避免刺眼的强红强绿

### 学习辅助

- **收藏 / 标记**重点题
- **错题自动归纳**，支持「只练错题」
- **个人笔记**：每道题可以写自己的考点笔记
- 完成后给出正确率、错题概览

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `A` `B` `C` `D` | 选择答案 |
| `←` `→` | 上一题 / 下一题 |
| `空格` | 下一题 |

## 本地使用

```bash
git clone git@github.com:ahazx/options-quiz.git
cd options-quiz
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

也可以直接双击 `index.html`，无需服务器。
